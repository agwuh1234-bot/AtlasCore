Установить Atlas

На iPhone: нажмите «Поделиться» → «На экран Домой», оставьте «Открывать как веб-приложение» включённым и нажмите «Добавить».

Настройки

Atlas может автоматически озвучивать свои ответы.

Кнопка ✎ разрешает изменения только для следующей команды.
