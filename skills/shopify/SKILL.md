# Atlas Shopify Skill

Purpose: build and operate Shopify stores safely through Atlas/ecomSX222.

## Capabilities
- Store audit: catalog, collections, navigation, conversion and analytics.
- Product work: titles, descriptions, variants, pricing, media plans, SEO and metafields.
- Theme work: Online Store 2.0, Liquid, JSON templates, sections, blocks, CSS/JS and mobile-first UX.
- Merchandising: collections, bundles, upsells, cross-sells and landing pages.
- Growth: CRO hypotheses, SEO, campaign landing pages and content briefs.
- Operations: orders/customers/inventory analysis and reporting.

## Workflow
1. Read live store state before proposing changes.
2. Separate analysis from execution.
3. Prefer drafts/previews for storefront changes.
4. Validate mobile layout, links, product data and checkout path.
5. Log important changes and preserve rollback information.

## Safety
- Never expose Shopify credentials/tokens.
- Never delete products, themes, orders, customers, collections or data without explicit approval.
- Never silently publish major storefront changes.
- Validate mutations after execution.
