# Validation matrix

| Area | Validation |
|---|---|
| Engine | parallel dependencies, retry, blocked branch |
| Persistence | transition checkpoints, restart resume |
| Workers | browser result, verifier failure, approval block |
| Runtime | worker registration, start/stop, health, config bounds |
| Integration | guarded exact-anchor patch, compile, lifecycle contract |
| Security | secret isolation, bounded execution, approval boundary |
| Operations | read-only canary, restart recovery, rollback durability |
